CONTEXTE
===============================================================
On construit, dans "Approche 2/", un pipeline générique d'inférence
variationnelle par normalizing flow pour échantillonner une distribution
cible non normalisée w_J(theta) (prior de Jeffreys tilté), connue
uniquement via un oracle ponctuel log_w_J(theta).

w_J(theta) ∝ sqrt(det J(theta)) * exp(-lambda_star * c(theta))
log_w_J(theta) = 0.5 * logdet(J(theta)) - lambda_star * c(theta)

Le pipeline (oracle -> flow -> diagnostics) doit être directement réutilisable

ETAPE 4 — flow.py
===============================================================
Implémenter dans flow.py :
  class CouplingLayer(nn.Module):
    - split theta en (theta_A, theta_B) selon un masque binaire fixe
    - MLP s(theta_A), MLP t(theta_A) (2-3 couches, hidden_dim de config)
    - forward(theta) -> theta_out, log_det   (theta -> version transformée,
      utilisé pour log_prob / inverse selon convention choisie)
    - inverse(theta) -> theta_out, log_det   (sens opposé)
    - alterner le masque A/B entre couches successives (paramètre layer_idx)

  class RealNVPFlow(nn.Module):
    - empile n_coupling_layers CouplingLayer
    - base distribution N(0, I_dim)
    - sample(n: int) -> theta: Tensor[n, dim]   (z~N(0,I) -> forward)
    - log_prob(theta: Tensor[n, dim]) -> Tensor[n]  (inverse -> log q0(z) - log|det|)

Docstring de module précisant l'interface générique (entrée/sortie stables
pour réutilisation SVGD/score-based).
